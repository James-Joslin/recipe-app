## [Unreleased]

### Added

## [0.1.0] - 2026-09-06

### Added

- Barebones Next.js frontend.
- ASP.NET Core 8 C# API with recipe list/create endpoints.
- FastAPI companion service with health and recipe-count endpoints.
- PostgreSQL 17 schema managed by Alembic.
- Neo4j 5 schema managed by independent ordered Cypher migrations.
- Development and production Dockerfiles and Compose stacks.
- Sample development and production environment files.
- Container-based workflow scripts and GitHub CI configuration.
- Contribution, security, support, conduct, and licensing documentation.
