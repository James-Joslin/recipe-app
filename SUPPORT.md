# Support

Start with the [README](README.md), especially the troubleshooting and database
migration sections.

For reproducible bugs, include the command used, the service that failed, and
sanitised logs. Do not include `.env` files, passwords, tokens, database dumps,
or private recipe data.

Feature requests should explain the user problem and the smallest useful
solution. Security issues belong in [SECURITY.md](SECURITY.md), not in a
public issue.
