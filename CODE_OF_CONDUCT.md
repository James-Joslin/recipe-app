# Code of Conduct

We want Recipe App to be a welcoming, respectful, and constructive project.

Participants must not engage in harassment, discrimination, personal attacks,
threats, or deliberate disruption. Use inclusive language, assume good intent,
and focus feedback on the work.

Project maintainers may remove comments, reject contributions, or restrict
participation when behaviour conflicts with these standards. Report concerns
privately to the maintainers listed in the repository rather than escalating a
public thread.
